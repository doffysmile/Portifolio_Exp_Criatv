## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar um portfólio pessoal totalmente personalizado.

A proposta foi desenvolver uma página que reunisse:

- Minha apresentação pessoal  
- Informações sobre minha trajetória acadêmica  
- Principais projetos desenvolvidos no GitHub  
- Interesses pessoais e hobbies  
- Páginas temáticas dedicadas a assuntos que fazem parte da minha identidade  

O projeto também foi pensado como uma forma de praticar desenvolvimento Front-End, estruturação de interfaces e organização visual de conteúdo.

---

## Visual

O design principal foi inspirado na estética **Matrix/Cyberpunk**, utilizando:

- Fundo escuro  
- Tons neon em verde  
- Fonte estilo terminal/programação  
- Interface minimalista 

O tema era livre, e escolhi esse devido sua simplicidade e conexão com programação e tecnologia, e claro, por ser um de meus filmes favoritos.
